# APEX Detailing — Telegram Mini App

Клиентское веб-приложение премиального автодетейлинга для Telegram (Mini App / WebApp).

## Что это

Рабочий прототип на чистом HTML/CSS/JS (без сборки и зависимостей), реализующий структуру из
документа `Структура приложения — APEX`: каталог услуг, детейлинг-паспорт автомобиля, запись
на визит, корзина с промокодом, оплата, отслеживание статуса заказа в реальном времени, история
заказов, гараж (несколько автомобилей), профиль с программой лояльности.

Данные хранятся в `localStorage` браузера — бэкенда пока нет, это готовый к интеграции фронтенд.
Приложение использует [Telegram Web App SDK](https://core.telegram.org/bots/webapps): тема
оформления, нативная кнопка «Назад», тактильная отдача.

## Структура

```
index.html        точка входа
css/style.css     дизайн-система (графит + лёд), все компоненты
js/data.js        иконки, каталог услуг, состояние (seed-данные)
js/app.js         роутинг, экраны, обработчики событий, интеграция с Telegram SDK
```

## Подключение в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → выберите бота → **Bot Settings → Menu Button**
   (или `/newapp` для полноценного Mini App) и укажите URL страницы GitHub Pages этого репозитория.
2. Готово — кнопка меню бота откроет приложение внутри Telegram.

## Локальный запуск

Просто откройте `index.html` в браузере, либо поднимите статичный сервер:

```
npx serve .
```
